AgentTown

Replay an AI coding agent session as a pixel-art town. Files are buildings. Tests fail → smoke. Tests pass → fireworks.

Drop a .jsonl session here
0.0s

Where are my sessions?

  • Claude Code: ~/.claude/projects/<project>/*.jsonl
  • Codex CLI: ~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl

Or run npx @barood-labs/agenttown in a terminal to replay your latest session, or npx @barood-labs/agenttown --watch to watch the town build live while your agent works. Hover or click a building to inspect it.

🔒 Everything runs locally in your browser. Your session file is never uploaded anywhere.
